# ai-uc-rag-evaluation
This repository contains a reference implementation for the AICE RAG Evaluation reusable pattern.

## Reference Implementation

The reference implementation is stored in the `reference/` folder, which contains the scripts, configurations, and Docker Compose setup needed to clone and run all the agent services. The actual code repositories are pulled from GitHub during setup using the provided scripts.

This is targeted towards developers looking to understand how to implement the RAG Evaluation pattern in their own projects, with a focus on modularity, best practices, and ease of local development.
